# Two-device online test (LIV Football)

You need two devices (or a phone and a laptop) and the shared claude.ai game page, opened on both.
The GitHub Pages copy is offline-only and cannot be used for this.

Tick each box. Note the device (A or B) and what you saw if a step fails.

## Setup
- [ ] A: open the shared game link and create a club with a name and crest
- [ ] B: open the same link and create a different club

## Clubs and crests
- [ ] A: the Online league screen lists club B within a few seconds
- [ ] B: club A's crest shows the same picture as on A
- [ ] A: change the crest; B shows the new crest after a few seconds

## Photos
- [ ] A: add a photo to a player
- [ ] B: the same player shows that photo
- [ ] A: remove the photo; it disappears on B
- [ ] A: Settings -> "Remove all photos (for everyone)" clears photos on both devices

## Switch club and links
- [ ] B: open a `#club=` link for club A; the right club loads
- [ ] B: Switch club works and returns to club B with its squad intact
- [ ] A: "Find your club" finds club A after clearing browser storage

## Shop, world, league
- [ ] A: buy a pack; stock count changes on B
- [ ] Host: start a season; both devices show the same fixtures
- [ ] Play a match on A; the table updates on B

## No sign-in
- [ ] B opens the link in a private window and can play without signing in
